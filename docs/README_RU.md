# 🔴 ИСПОЛЬЗУЙТЕ НА СВОЙ СТРАХ И РИСК

> [!CAUTION]
> **Возможны потеря данных, исходного серийного номера SN и MAC-адресов или их изменение.**
>
> X110 — модель Wi-Fi. Wi-Fi и Bluetooth не зависят от IMEI, но после повреждения NV-данных их работа не гарантируется.
>
> **ТОЛЬКО SM-X110 — BIT 6 / U6. Не для другой модели или ревизии.**
>
> ЭКСПЕРИМЕНТАЛЬНЫЙ ПАКЕТ — НЕ ПРОВЕРЕН НА ПЛАНШЕТЕ. УСПЕХ НЕ ГАРАНТИРУЕТСЯ.

## Краткая инструкция

1. Скачайте экспериментальный ZIP из Releases и полностью распакуйте.

2. При необходимости установите VC++ и USB-драйверы из 03_DRIVERS. Для MTK: правой кнопкой по INSTALOVAT_MTK.cmd → Запуск от имени администратора.

3. Запустите 02_SP_FLASH_TOOL/SPFlashToolV6.exe.

4. Download-XML: выберите 01_SPFT_RECOVERY/download_agent/flash.xml. Authentication File: auth_sv5.auth из той же папки.

5. Выберите Download Only. Должны быть отмечены 16 строк с заполненными путями Location. Остальные параметры не меняйте.

6. Нажмите Download и подключите планшет по USB. Если он не определяется, удерживайте питание + уменьшение громкости до вибрации и отпустите. Не отключайте кабель во время записи.

7. После Download OK отключите USB. Для Download Mode удерживайте обе кнопки громкости и подключите USB; запрос подтвердите коротким нажатием увеличения громкости.

**При любой ошибке ОСТАНОВИТЕСЬ и не повторяйте ту же запись. Если Download Mode не появился, не запускайте новую запись.**

После появления Download Mode можно установить полную официальную прошивку SM-X110 BIT 6 через Odin. Полная прошивка в малый пакет не включена.
